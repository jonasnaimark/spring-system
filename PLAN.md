# Motion System — Future Work

## Missing Transition Patterns

- **Tab Switch** — switching between peer-level tabs (not navigation). Subtle horizontal positional nudge + crossfade. Sits between Push and Cross Fade in character.
- **Accordion / expand-in-place** — inline expansion of a row or item (settings row, FAQ). Different from Grow which is a hero expansion; this stays in context.
- **Push & Fade persistent-bar variant** — parity with the Push tab which has a persistent-bar mode.

---

## Micro Animations Section

Three groups, ordered from functional to expressive:

### Feedback (functional, still expressive)
- **Success screen** — checkmark draw + subtle scale-in of confirmation content
- **Error shake** — input or card shakes horizontally, brief and sharp
- **Progress ring** — circular fill for step completion or upload progress

### State Transitions (utilitarian but alive)
- **Spinner / loader** — branded, not a generic CSS spinner
- **Badge counter** — number ticks up/down with a small vertical slide
- **Toggle / switch** — spring snap between on/off states

### Branded Moments (expressive, higher energy)
- **Like / save** — tap triggers a small burst or bounce, the heart fills
- **Confetti burst** — booking confirmed, goal reached, first review
- **Avatar group** — avatars slide and overlap as people join
- **Number reveal** — price or stat counts up on load, slight ease-in

### The story to tell
Branded moments justify a higher-energy spring — faster, slightly more bounce, a bit theatrical. That contrast is the interesting point: same token system, different tuning, different mood. Functional vs. celebratory.
